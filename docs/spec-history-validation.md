# 规则与规格查看验证

更新日期 2026-10-08。分支 `codex/spec-history`，基于已合并的实时进度 PR #11。

页面提供当前配置项目的 YAML、项目历史行为版本、编译规则、复制和下载、两版本源内容差异及关联运行跳转。当前 YAML 不导入被测适配器；历史记录来自已有 specs 表，下载用认证 fetch。跨项目对比拒绝，未知版本返回 404，源内容有读取上限。源内容、编译规则和差异沿用网页脱敏，DOM 只按文本渲染。

没有修改数据库结构、版本去重规则或已有 CLI 输出。版本按编译规则去重，注释和排版不会生成新版本，历史源内容保留第一次保存的文本。当前 YAML 总是从服务端配置项目读取，历史列表跟随页面选择。历史关联运行最多列最近 50 条并提供总数。没有版本 ID 的旧运行不显示跳转。历史源内容和版本比较暂为网页专属功能，页面明确注明。

验证只使用临时项目、私有数据库、固定适配器与假模型。没有读取或写入 `.env`，没有调用真实提供商，也没有修改仓库示例。

- 新增 **11 项**测试通过，覆盖读取不导入适配器、不生成运行/版本，真实运行版本差异与关联，注释变化去重，YAML/JSON/文本历史兼容，认证、脱敏、UTF-8 下载字节、404、跨项目 422、超长 413 和关联运行 50 条上限。
- 最终本机全量 **631 项通过**，11 个既有警告。浏览器检查随全量测试串行执行。
- 原有浏览器 **92 项**断言保留，新增 **10 项**，共 **102 项通过**。真实 FinCare 副本生成两个行为版本，验证当前与历史源内容、脚本注入按文本显示、复制、认证下载、运行与规格双向跳转及着色差异，页面没有脚本错误。
- 浏览器验证发现返回规格的慢请求会覆盖之后选择的对比版本。已将下拉框同步移到请求发起时，响应不再覆盖选择，整套浏览器检查重新通过。
- **19 组**旧 CLI stdout 字节和退出码一致，见 [逐项证据](spec-history-cli-output-evidence.json)。

下载保持显示内容的 UTF-8 字节，系统剪贴板可能转换换行。凭据和服务端绝对路径已隐藏时，复制与下载得到的是显示内容，不是未脱敏的源文件。未做真实提供商、PostgreSQL 实机或大规模版本列表验证。
