# 修复建议查看与复验验证

分支 `feature/fix-suggestions-view`，基于已合并的 PR A #8 和 Agent 可视化 PR #9。新增 CLI `suggestions list/show`、三个受保护的只读接口和 Project tools 中的 Fix suggestions。Agent 面板只增加批准结果里的“查看建议”链接。

共用实现展示 ID、时间、规则、文件、修复前运行、诊断和复验历史。`show --diff` 与下载按字节读取原始 diff，不做换行转换或内容脱敏。网页将 diff 逐行作为文本显示，增删行着色，hunk 使用灰色。复制操作提交原始文字；操作系统剪贴板可能转换 CRLF/LF，浏览器测试比较行内容，下载和 CLI 则比较完整字节。

没有 apply CLI、网页按钮或服务端应用接口。建议通过已有工具批准后保存，人在项目目录审阅并执行相对路径的 `git apply`，然后复验。网页复验和 CLI 共用判定并在建议目录保存历史；同秒多次记录不覆盖。没有匹配建议的 Triage 保持既有输出。

验证只使用临时项目、临时数据库和假客户端。没有读取或写入 `.env`，没有真实模型调用，没有修改仓库示例或用户已有服务。

- 全量测试 **611 项通过**，11 个既有警告，无失败或错误。最后只读 CLI 调整另跑新测试 **15 项通过**。
- 新测试覆盖 CLI/API JSON 一致、原始 diff 字节与 CRLF/UTF-8、真实 `git apply --check` 和应用、ALL_FIXED/PARTIAL、匹配分诊提示、认证、无效 ID/超长 ID/路径穿越、符号链接边界、不覆盖历史、只读 CLI 不创建数据库，以及根目录别名下完整读取的哈希匹配。
- 浏览器原有 **73** 项检查和断言保留，新增 **12** 项，共 **85** 项通过。实际 Chrome 流程准备真实工具建议、列表和详情、复制、带认证下载、批准卡片跳转、本地应用和网页复验。复验历史文件真实存在，结论 ALL_FIXED、fixed=4。注入 HTML 仍为文本，页面无脚本错误。
- 19 组既有 CLI stdout 字节与退出码再次与重构前一致，包括没有修复建议时的 Triage。[逐项证据](fix-suggestions-cli-output-evidence.json)由 `scripts/check_cli_output_parity.py` 生成，没有归一化输出。
- 修复测试发现的 Windows 短路径问题。源码读取现在与修复工具使用相同的真实根目录计算相对路径；目录别名回归测试通过。
- 所有建议读取拒绝目录/文件符号链接和 junction，单文件上限 2 MB。响应只展示相对文件名和命令。原始 diff 是源码内容，复制和下载保留它。

真实模型演示已在 `docs/demo-script.md` 增补操作步骤，明确标为“未在本次验证”。未提供真实模型输出。历史建议保存在服务器的配置项目中，不会同步到用户本机。Linux 行为由 GitHub CI 验证，运行结果记录在 PR。
