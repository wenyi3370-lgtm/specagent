# Agent 执行可视化验证

分支 `feature/agent-visualization`，基于已合并的 PR A。提供实时执行时间线、Responses 增量文字、历史日志、下载和继续活动会话。

时间线展示工具名、脱敏参数、结果、审批停放、恢复、模型请求和最终结果。查看详情不执行工具。历史日志在网页刷新、服务重启或会话过期后保留。失效会话不能恢复执行；历史审批不会自动变成新的执行请求。

新接口使用 Agent API 的认证和启用检查。流在发送响应前取得会话锁。客户端断开后，已批准动作继续完成，结果保存到同一日志；重试审批不重复执行。日志 ID、目录包含关系、符号链接和读取大小有限制。新事件、错误与历史响应隐藏服务端路径和敏感值。没有增加应用补丁或修改判定的权限。

验证使用临时项目、临时数据库和假模型，不读取或写入 `.env`，不写仓库示例。

- 新增 12 项测试覆盖事件顺序、真实增量在模型结束前送达、停放与恢复、函数调用与输出配对、跨片段凭据脱敏、断流后恰好执行一次、认证、历史持久化、分页和路径边界。
- 原有浏览器 58 个检查保留，新增 15 个，共 73 个通过。实际 Chrome 验证了页面刷新后回看历史、恢复原审批、执行并分诊、原样确定性文字、日志下载及增量文字在模型结束前显示。脚本化模型明确标为测试，HTML 注入文本没有变成节点。
- 原有 Agent API、循环与工具测试 65 项通过。
- 全量测试 596 项通过，11 个既有警告，无失败或错误。19 组 CLI 输出字节与退出码再次与改动前一致。
- 真实模型流、外部服务和多进程会话共享没有在本次验证。提供商必须支持 Responses streaming。很短的回复可能在安全缓冲完成后一次显示。

全量测试与 GitHub CI 结果记录在 PR 中。CLI 默认仍为原来的同步模型调用，增量模式仅在网页流请求期间开启。
