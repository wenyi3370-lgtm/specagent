# 运行管理验证

更新日期 2026-10-08。分支 `codex/run-management`，基于用户批准合并的项目创建 PR #14。

## 可见行为

Run history 搜索运行 ID、标签及 Agent，提供状态、当前基线和正常历史/回收站筛选。每页 25、50 或 100 条，有总数和上一页/下一页；搜索先筛选再分页，能查看超过 200 条的历史。可选择本页运行对比，也可填写其他页的基线 ID。

标签可修改或清空，最多 256 字。显示值经过网页脱敏，保存会替换整个标签，页面明确提示这一点。删除面板展示项目、标签、执行和违规数量及影响，输入完整运行 ID 后才能确认。数据库再次检查当前基线、running 状态和是否已删除；取消注册表中的活动运行也被拒绝。编辑与删除成功提示等待历史和指标刷新。

删除采用独立 `run_trash` 表记录 ID 与时间。默认列表、项目数量和指标排除回收站记录；恢复后重新纳入统计。执行、轨迹、违规、规格及建议/复验关联保留，按 ID 的运行、分诊和下载仍可读取。历史规格关联保留并显示原有运行数量。基线不能设为回收站中的记录，失败会回滚而保留原基线。这里没有永久删除。

## 新接口

| 请求 | 输入与结果 |
|---|---|
| `GET /api/runs/search` | `project_id`，`q` 最多 200 字，`status=all/running/completed/canceled/error`，`baseline=all/yes/no`，`view=active/trash`，`limit=1..100`，`offset>=0`。返回 `project_id/items/total/limit/offset/has_more/view`，items 保留旧摘要字段并附加 `deleted_at` |
| `GET /api/runs/{id}/management` | 返回 `run/deleted_at/executions/violations/blocked_reason/can_delete`，用于预览影响 |
| `PATCH /api/runs/{id}/label` | `{ "label": "评审版本" }`，空字符串可清空 |
| `DELETE /api/runs/{id}` | `{ "confirm_run_id": "完整运行 ID" }`，移入回收站 |
| `POST /api/runs/{id}/restore` | `{}`，恢复，已恢复时仍成功 |

写请求返回更新后的 management 结构。未知运行为 404，保护或重复删除为 409，确认 ID 不匹配及字段校验失败为 422。错误使用固定代码，校验响应去除输入和错误上下文。所有接口复用 API 认证；三个写接口强制 JSON，无 token 时校验环回 Host。请求不能设置配置、规则路径、适配器、端点或门禁。标签等显示文字脱敏，HTML 使用文本节点。搜索转义 `%`、`_` 与反斜杠，用户输入不会成为 SQL。

旧 `GET /api/runs` 的列表结构、参数与摘要字段保持不变，但排除已移入回收站的记录。网页改用新分页接口。管理写入由私有 Store 方法供网页路由调用，没有注册为 Agent 工具，既有只读工具代理与工具分类测试保持通过。运行创建、测试判定与 CLI 命令没有新增字段或选项。

## 存储兼容与验证

初始化自动建立 `run_trash`，不改已有运行、执行、规格或违规列。旧库升级测试先删除新表模拟原库，再重新初始化，核对原运行内容一致并实际删除/恢复。基线设置和删除都使用条件写入，SQLite 的并发测试验证两者同时发生不会生成已删除的基线。

- 新增 21 项接口与存储检查。包括 207 条历史分三页全部读取且无重复、字面搜索、过滤、标签编辑与脱敏、证据和规格关联保留、恢复前后统计一致、基线与运行保护、预览后基线变化、重复与幂等操作、并发保护、旧数据库建表、参数边界、认证和 JSON/Host 限制。
- 本机全量从 665 项增至 **686 项，全部通过**，11 个既有警告。全量包含真实浏览器测试。
- 浏览器保留原有 123 项检查，新增 14 项搜索、筛选、标签的 HTML 文本渲染、删除影响与 ID 确认、回收站恢复、空状态、28 条真实离线运行的前后翻页及无页面错误检查，**137 项全部通过**。原有延迟响应测试的拦截地址改为新分页接口并允许匹配子路径，清理等待中的请求，原断言没有删减或放宽。
- 19 组旧 CLI stdout 字节与退出码一致，见 [逐项证据](run-management-cli-output-evidence.json)。

实际 Chrome 页面截图由临时项目生成，位于本机可视化附件目录的 `run-management.png`。测试只使用临时 SQLite、临时项目及离线适配器，没有修改用户正在运行的服务或仓库示例，没有使用真实提供商。

分页基于 offset，新增运行时页面内容可能变化。状态仍为 running 的中断记录继续受保护。PostgreSQL 并发、大型数据库性能、移动端、账号权限和系统无障碍尚未实机验证。CI 以功能 PR 的 pytest、browser、两套 gate 与 action 自检为准。
