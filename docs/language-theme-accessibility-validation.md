## 实现范围

顶部提供中文、English 和原始文案，以及深色、浅色、跟随系统。默认保留原有混合文案和深色，不改变旧控件行为。当前标签页 sessionStorage 保存偏好，重载保留，独立浏览器上下文不继承。非法值恢复默认，存储被禁用时仍可切换并提示不保留。切换不请求 API，不修改服务端配置或账号设置。

固定说明、操作、动态状态和可访问名称可翻译。输入值、项目名称与说明、运行标签、实际操作者、模型名称、规格、响应、轨迹、违规、审批摘要和确定性 CLI 输出保留原文。目录匹配完整字符串，固定句式保留数据部分；不对证据做逐词替换。回到原始文案会恢复已保存的界面原文。

新增跳到主内容和 main，补齐控件名称、表格列 scope、状态播报和滚动 pre 的键盘焦点。保留 reduced-motion，设置窗口循环当前可聚焦内容。窄屏顶部控件可换行，指标从固定六列改为两列；宽表格继续在容器内滚动。
