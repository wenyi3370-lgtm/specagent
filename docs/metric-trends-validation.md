# 六项指标趋势验证

更新日期 2026-10-08。分支 `codex/metric-trends`，基于已合并的规格查看 PR #12。

Metrics 下方展示行为通过率、Critical 违规率、新回归数、FLAKY 比例、工具准确率和延迟 P95。支持最近 7/30/90 天与全部时间范围、精确数值表、数据点焦点与键盘跳转。原生 SVG 按真实开始时间绘图，比例轴固定 0–100%，时间按 UTC 显示。没有新增浏览器图表依赖。

`compute_metric_history` 复用 `compute_run_metrics` 和 `regression.diff_runs`。新增受保护的 `GET /api/metrics/history` 返回查询窗口、当前基线 ID、匹配总数和截断标记。查询先按项目、时间和已结束状态筛选，再取最新记录。最多 500 次，超过上限会明确提示，历史曲线不会被现有 100/200 条列表截断。新回归与响应注明的当前基线比较，更换基线会重算历史比较；无基线时明确未评估。这不是过去 CI 门禁结果的记录。

新增页面请求使浏览器复现了一个已有选择问题：刚结束的运行尚未进入 Project tools 列表时，Triage 会查看上一轮。现在展示运行时立即将其加入并选中，稍晚返回的旧列表也保留当前显示的运行。趋势跳转到不在最近 200 条列表中的记录时同样可正确使用工具。原有断言没有删除或放宽。

验证只在临时项目与数据库中进行。没有读取或写入 `.env`，没有真实模型或外部服务调用，没有改动仓库示例。

- 新增 **12 项**测试通过，包括真实固定/缺陷/修复运行与共用指标、当前数值的一致性，基线变化，时间筛选在限量前执行，已取消与未结束状态，项目隔离，空状态，认证与脱敏，参数边界，真实 FLAKY/错误执行，以及 205 次记录超过旧列表上限后的读取。
- 本机全量 **643 项通过**，11 个既有警告。
- 浏览器原有 **102 项**断言保留，新增 **8 项**趋势检查与 **1 项**当前运行选择回归，共 **111 项通过**。实际页面验证六张曲线、UTC 时间、精确值与当前六项指标一致、范围切换、键盘跳转、HTML 标签按文本显示和空项目，没有脚本错误。
- **19 组**旧 CLI stdout 字节与退出码一致，见 [逐项证据](metric-trends-cli-output-evidence.json)。

数据库结构和已有 CLI 输出保持不变。趋势只展示 completed/canceled 记录，运行中的数值仍在实时进度卡片中查看。没有做大型数据库、PostgreSQL 实机性能、移动端系统无障碍或真实提供商验证。
